# Changelog

What’s new in TaxTrack. Plain language only.

## [Unreleased]

## [0.2.0] - 2026-11-13

### Added

- Rental properties. Turn them on in the menu.
- Log rent received, and the usual rental expenses, for each address.
- Summary, Excel, and PDF include rentals while the switch is on.
- Depreciating assets. Purchase price, effective life, and the yearly decline in value.
- Car kilometres on Expenses, at the ATO cents per kilometre rate.
- Email sign-in is required before the summary. Records sync as encrypted text.
- Log off, in the menu, returns to the sign-in page.
- Change password from Account, while signed in.

### Changed

- Rental addresses stack in a list. Add address opens in a box.
- Pinch zoom is off. Text size in the menu still changes the type.
- Opening screen says the records are zero-knowledge encrypted.
- Sign-in opens that account's records. Later changes are stored with it.

## [0.1.0] - 2026-11-13

### Added

- Private tax and EOFY organiser. Records stay in this browser.
- Working-from-home hours at 70 cents. Cents disregarded.
- Expenses with a photo, PDF, or Word invoice.
- 2027–28 stays hidden until 1 July 2027.
- Excel and PDF reports, with the TaxTrack name and logo.
- Dark opening screen.
- Help, from the menu.
